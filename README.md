# Inkwell

A premium notepad Android app with a modern, beautiful design. Built from scratch with Kotlin, Jetpack Compose, and Material 3.

## Features

- **Create, edit, and delete notes** with a clean, distraction-free editor
- **Search** through all your notes instantly
- **Pin important notes** to the top
- **8 color themes** for your notes
- **Grid or list view** — switch with one tap
- **Dark mode** with dynamic color support (Android 12+)
- **Smooth animations** and responsive UI
- **Local storage** with Room database — your notes stay on your device

## Tech Stack

- **Kotlin** + **Jetpack Compose**
- **Material 3** design system
- **Room** for local database
- **Navigation Compose** for screen transitions
- **MVVM** architecture

## Building

```bash
cd inkwell
./gradlew assembleDebug
```

The APK will be at `app/build/outputs/apk/debug/app-debug.apk`

## Requirements

- Android 8.0 (API 26) or higher
- Android Studio for development
